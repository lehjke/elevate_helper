# Elevate Helper: инструкция пользователя

Дата обновления: 11 августа 2026

Эта инструкция описывает базовый сценарий работы с Elevate Helper: выбор режима и папки, запуск расчета, очередь задач, формирование отчетов, пакетный запуск и типовые проблемы.

## 1. Что нужно перед началом

- Windows 10/11.
- Установленный Peters Research Elevate.
- Microsoft Excel на той же Windows-машине, где формируется отчет.
- Исходный `.elvx`-файл или структура проекта с папками `Office`, `Res` и `Hotel`.
- Release-сборка Elevate Helper. Отдельная установка .NET и Windows App Runtime для пользователя обычно не требуется.

Важно про Excel: во время генерации отчета приложение открывает отдельный Excel COM-процесс, сохраняет `.xlsx`, экспортирует `.pdf` и закрывает созданный процесс. Уже открытые пользователем окна Excel не должны закрываться приложением.

## 2. Быстрая карта интерфейса

| Блок | Что выбрать | Когда используется |
| --- | --- | --- |
| Верхняя панель | Язык, версия, скрытие окон Elevate | Версия отображается рядом с названием приложения; при запуске приложение проверяет последнюю релизную версию на GitHub. |
| Папка Elevate | Рабочая папка с `.elvx` | Обычный расчет одной группы или сценария. |
| Режим | Один проект / Пакет | Выбор остаётся за пользователем; анализ папки только показывает рекомендацию. |
| Тип здания | Офис / Жилье / Гостиница | Определяет подготовку `.elvx` и шаблон отчета. |
| Действия | Запуск, Утренний пик, печать отчетов | Ручной запуск и ручное формирование отчета. |
| Очередь задач | Карточки расчетов | Прогресс, остановка, повтор ошибки, печать и удаление карточки. |
| Редактор и пакетный запуск | Зависит от выбранного режима | Редактор работает с одной папкой; пакетный запуск — с корнем проекта. |

## 3. Обычный расчет одной папки

1. В блоке **Папка Elevate** нажмите **Обзор** и выберите папку с исходным `.elvx`.
2. В блоке **Тип здания** выберите **Офис**, **Жилье** или **Гостиница**.
3. Нажмите **Запуск**. Для офисного проекта при необходимости можно запустить только утренний пик кнопкой **Утренний пик**.
4. Следите за карточкой в **Очереди задач**: там показаны статус и прогресс сценариев.
5. После завершения нажмите **Печать отчета** или **Печать отчетов** на карточке задачи.

Для `Office` полный запуск создает сценарии `morning` и `lunch`. Для `Residence` и `Hotel` расчет выполняется в выбранной рабочей папке.

## 4. Очередь задач

- Активные и ожидающие задачи всегда отображаются выше завершенных.
- Завершенные и досрочно остановленные задачи идут ниже активных.
- Ошибочные задачи показываются внизу очереди.
- Кнопка **Остановить** доступна только у активного расчета.
- **Стоп очереди** отменяет только ещё не начатые задачи, а **Остановить все** — и ожидающие, и активные; перед действием показывается подтверждение.
- Досрочная остановка не считается ошибкой: отчет можно сформировать из уже рассчитанных данных Elevate.
- При остановке Elevate Helper закрывает расчет Elevate и автоматически отвечает **Нет** в диалоге сохранения Elevate.
- Кнопка **Повторить** появляется у задачи, завершившейся ошибкой.
- Крестик в правом верхнем углу карточки убирает из очереди завершенную, остановленную или ошибочную задачу; в течение 10 секунд действие можно отменить.

Останавливать расчет удобно, если концепция уже явно проигрывает по результатам и нет смысла ждать полный прогон. Если `batch_results.csv` уже успел появиться, отчет будет строиться по доступным результатам.

## 5. Формирование отчетов

- Шаблоны лежат в папке `.example`: `Office.xlsx`, `Residential.xlsx` и `Hotel.xlsx`.
- Выходные файлы сохраняются в корневую папку проекта, а не внутри `morning` / `lunch`.
- Для `Office` к имени добавляется суффикс сценария: `morning` или `lunch`, чтобы отчеты не перезаписывали друг друга.
- При пакетном запуске отчеты формируются автоматически после завершения расчета.
- Генерация отчетов выполняется последовательно, чтобы не запускать несколько Excel COM export одновременно.

Типовые имена файлов:

- `<Project> <Building>.xlsx`
- `<Project> <Building>.pdf`
- `<Project> <Building> morning.xlsx`
- `<Project> <Building> morning.pdf`
- `<Project> <Building> lunch.xlsx`
- `<Project> <Building> lunch.pdf`

## 6. Пакетный запуск проекта

1. Выберите режим **Пакет** под полем рабочей папки.
2. В карточке **Пакетный запуск проекта** выберите корень проекта.
3. Укажите количество параллельных расчетов или включите **Без ограничений**.
4. Нажмите **Запустить проект**. Приложение само найдет группы и создаст карточки задач.
5. Если `.elvx` найден вне `Office` / `Res` / `Hotel`, появится отдельное окно выбора типа здания.

Перед стартом открывается сводка. Пропущенные папки, конфликты типа здания и нечитаемый `BuildingType` показываются на выбранном языке вместе с путём.

Ожидаемая структура проекта:

```text
Project/
├─ Office/
│  ├─ G1/
│  │  └─ *.elvx
│  └─ G2/
│     └─ *.elvx
├─ Res/
│  └─ G1/
│     └─ *.elvx
└─ Hotel/
   └─ G1/
      └─ *.elvx
```

Правила:

- в каждой папке группы должен быть один `.elvx`-файл;
- `Office` запускается как утренний плюс обеденный пик;
- `Res` запускается как `Residence`;
- `Hotel` запускается как `Hotel`.

## 7. Редактор ELVX

- Выберите режим **Один проект**, затем откройте редактор из карточки файла расчета.
- Открывается отдельным окном и использует текущую рабочую папку и выбранный тип здания.
- Можно загрузить существующий `.elvx` или создать файл из встроенного шаблона.
- Редактор разделён на вкладки **Проект**, **Анализ**, **Трафик**, **Здание** и **Лифтовая группа**.
- Можно изменять проект, анализ, пассажиропоток, добавлять и удалять этажи и лифты, настраивать кабины, двери, домашний и обслуживаемые этажи.
- При нескольких `.elvx` редактор предлагает выбрать файл; существующий другой output не перезаписывается без подтверждения.
- При несохранённых изменениях закрытие или загрузка другого документа требует явного решения.
- Горячие клавиши: `Ctrl+S` — сохранить, `Ctrl+O` — загрузить файл, `Ctrl+Z` — отменить несохранённые изменения, `Ctrl+W` — закрыть окно.

Ограничение: редактор перестраивает связанные секции для поддерживаемых операций, но не заменяет полный редактор Elevate для неподдерживаемых или сложных секций проекта.

## 8. Локальная сборка на Windows

Для проверки сборки из исходников можно использовать скрипт в корне репозитория:

```cmd
.\build-local.cmd -Clean -Test
```

- Если PowerShell запрещает запуск `.ps1`, используйте `build-local.cmd`: он запускает скрипт с `ExecutionPolicy Bypass` только для текущего вызова.
- Если `dotnet` не найден, установите .NET SDK внутри Windows/Parallels и откройте новый терминал.
- Если NuGet временно недоступен, можно попробовать `.\build-local.cmd -IgnoreFailedSources`.

## 9. Обновление приложения

При запуске Elevate Helper сравнивает установленную версию с последним релизом на GitHub. Если доступна новая версия, появится окно с предложением обновиться.

После подтверждения приложение скачает `setup.exe` из последнего релиза, запустит установщик в тихом режиме и закроется. Если автоматическая установка не стартовала, скачайте `ElevateHelper-win-x64-...-setup.exe` вручную со страницы релиза.

## 10. Частые проблемы

### Elevate не найден

Проверьте установку Peters Research Elevate или задайте переменную окружения `ELEVATE_EXE_PATH` с полным путем к `Elevate.exe`.

### Приложение не управляет окном Elevate

Запустите Elevate Helper и Elevate с одинаковыми правами пользователя.

### Microsoft Excel COM is not available

Установите Microsoft Excel на Windows-машине, где формируется отчет.

### Не найден шаблон `.example`

Используйте release-сборку или проверьте, что папка `.example` лежит в корне репозитория при запуске из исходников.

### Сборка блокируется файлом приложения

Закройте запущенный `ElevateHelperWinUI.exe` и повторите сборку.
