# Elevate Helper v2.0.3

## Changed

- moved the main window closer to a macOS-style desktop layout with grouped cards, calmer icons, and consistent rounded controls
- replaced the toolbar language ComboBox with a rounded flyout selector to keep the menu aligned under the language field
- aligned the project batch "unlimited runs" option with the parallel run count input and kept its checked state on the blue app accent
- normalized accent colors across primary actions, segmented controls, beta toggles, status surfaces, and language selection
- clipped the left scroll column to the same corner radius as its cards so hidden content no longer appears outside the rounded area
