# Elevate Helper v2.0.2-preview.1

## Preview

- added a manifest-backed workflow runner that records run status, steps, errors, and generated artifacts
- added run history snapshots and service-level retry support for the latest failed run
- fixed report door width/type resolution by preferring ELVX project metadata and using `DoorPreOpening` for ambiguous door timing pairs
- added extra unit coverage for report path resolution, door timing resolution, filename sanitizing, workflow manifests, history, and retry
- gated the project editor card behind the BETA checkbox
- included `.example` templates in release packaging and added release-script validation for required templates
- hardened Elevate launch monitoring and Excel COM cleanup during report generation

## Validation

- `dotnet test .\tests\ElevateHelper.Tests\ElevateHelper.Tests.csproj -c Release`
- Windows release packaging is expected to run in GitHub Actions on tag push
