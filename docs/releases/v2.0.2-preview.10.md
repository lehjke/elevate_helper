# Elevate Helper v2.0.2-preview.10

## Changed

- refreshed the main screen with an iOS-inspired grouped layout
- added light and dark iOS-style color resources
- softened cards, queue items, empty states, and toolbar surfaces with larger radii
- changed BETA from a checkbox to a compact toggle switch
- changed building type selection from radio buttons to segmented toggle buttons
- updated primary and secondary buttons to pill-shaped iOS-style actions

## Validation

- `xmllint --noout App.xaml Views/MainPage.xaml MainWindow.xaml`
- `dotnet test tests/ElevateHelper.Tests/ElevateHelper.Tests.csproj`
- Windows release packaging runs in GitHub Actions on tag push
