# Elevate Helper v2.1.2

- Removed ambiguous door timing mappings from report door detection: `650 ТО`, `1500 ЦО`, `1600 ЦО`, `1700 ЦО`, and `1800 ЦО`.
- Door width and opening type are now resolved only from door open and close times; door pre-opening no longer affects this choice.
- Updated report tests to cover the remaining deterministic door mappings.
