# Elevate Helper v2.0.2-preview.9

## Changed

- adjusted the default startup window to a taller desktop-oriented size
- increased card title typography for better hierarchy
- replaced filled card icon badges with quieter desktop-style icons
- removed the outer framed container from the main screen
- compacted the top toolbar and separated language/BETA controls from the content area
- emphasized primary run actions while making secondary and exit actions quieter
- added BETA badges to experimental cards
- reduced the empty queue panel height so the right work area feels less vacant

## Validation

- `xmllint --noout App.xaml Views/MainPage.xaml MainWindow.xaml`
- `dotnet test tests/ElevateHelper.Tests/ElevateHelper.Tests.csproj`
- Windows release packaging runs in GitHub Actions on tag push
