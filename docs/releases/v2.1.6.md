# Elevate Helper v2.1.6

- Hardened batch calculations with persistent queue state, interrupted-job recovery, per-folder execution leases, and overlap validation before launch.
- Preserved existing morning and lunch results through hashed scenario manifests and safer managed-file cleanup.
- Added an Elevate process watchdog with automatic restart and stricter process/window cleanup after calculations and result-file failures.
- Improved retry behavior so report-generation failures can be retried without rerunning completed calculations.
- Published Excel and PDF reports transactionally, prevented output-name collisions, recovered interrupted publications, and tightened owned Excel process cleanup.
- Added a single-instance guard and made update installation cancellation-aware, verified, and able to relaunch the application after a silent update.
- Strengthened ELVX editor validation and project discovery for arbitrary calculation folders.
- Expanded automated coverage for launch recovery, scenario state, queue persistence, batch discovery, editor validation, and report publication.
