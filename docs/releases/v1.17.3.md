# Elevate Helper v1.17.3

- fixed corrupted Cyrillic text in generated reports by loading Elevate CSV files with correct encoding fallback
- fixed localized decimal parsing so values like `3,60` are no longer interpreted as `360`
- fixed PDF/export print layout by preserving template workbook print setup during save/export
- fixed completed and failed jobs remaining in the WinUI job queue

## Improved

- added regression tests for `Windows-1251` CSV reading and localized decimal parsing in the report module
