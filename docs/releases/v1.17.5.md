# Elevate Helper v1.17.5

## Fixed

- fixed Excel report generation failure caused by `Print_Area` name conflicts during report save/export
- removed the fragile reopen step that could fail with `Unable to get the Open property of the Workbooks class`
- reset built-in and localized print names before assigning report `PageSetup`, then save/export in a single Excel session
- kept strict print column bounds for all report sheets:
  - `Титул`: `B:H`
  - `Оценка`: `B:AB`
  - `Лифтовая группа`: `B:J`
  - `Здание`: `B:H`
  - `Пассажиропоток`: `B:Q`
  - `Критерии`: `B:O`

## Improved

- added regression tests for detecting built-in and localized print layout names
