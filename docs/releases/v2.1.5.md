# Elevate Helper v2.1.5

- Added a localized `Hide Elevate` switch to the main toolbar; hidden mode remains enabled by default.
- Hidden mode is now applied continuously to every top-level window created by each active Elevate process, including windows that appear after `Run Batch` starts.
- The switch can show or hide Elevate windows while calculations are running.
- Only windows previously hidden by Elevate Helper are restored when hidden mode is disabled, leaving internal Elevate utility windows untouched.
