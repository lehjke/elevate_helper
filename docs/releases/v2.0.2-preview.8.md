# Elevate Helper v2.0.2-preview.8

## Changed

- redesigned the main screen into a desktop-oriented two-column layout
- moved language and BETA controls into the top toolbar with the app icon
- moved the run queue and status bar into the right work area
- compacted cards, buttons, spacing, and corner radii for a denser desktop utility feel
- increased the default window width for the new layout

## Validation

- `xmllint --noout Views/MainPage.xaml App.xaml MainWindow.xaml`
- `dotnet test tests/ElevateHelper.Tests/ElevateHelper.Tests.csproj`
- Windows release packaging is expected to run in GitHub Actions on tag push
