# Elevate Helper v2.0.9

- Reworked the ELVX editor around the current project workflow with Excel-like building and served-floor tables.
- Added automatic editor defaults for dispatcher mode, absenteeism, destination call stations, door timing, cabin area, acceleration, and jerk.
- Added Office morning-only support for project batch runs.
- Fixed Design 1 save confirmation handling when Elevate asks whether to save changes.
- Fixed report generation for express zones, technical floors, partially served stops, rounded parking population, and removed the 600 ТО door from report door detection.
- Improved task queue cards: failed jobs now show wrapped error text in a compact block with the full message available as a tooltip.
