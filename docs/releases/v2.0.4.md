# Elevate Helper v2.0.4

## Added

- Added `docs/USER_GUIDE.md` with a user-facing guide for normal runs, BETA project batch mode, the ELVX editor, reports, queue actions, and local Windows builds.
- Added `build-local.ps1` and `build-local.cmd` to the repository for local Windows builds.
- Added an early stop action to active job cards. Stopped jobs are not treated as failed and can still produce reports from completed Elevate data.
- Added a dismiss button for completed, stopped, and failed job cards.

## Changed

- Job cards are ordered as active/unfinished first, completed or stopped next, and failed jobs last.
- Scenario progress bars now use the app's blue accent color.
- Excel report generation now tracks the Excel COM process created by the report task and ensures it exits after export without closing user-owned Excel windows.
- README now links to the user guide and documents the queue cleanup behavior.
