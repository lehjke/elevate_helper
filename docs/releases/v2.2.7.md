# Elevate Helper v2.2.7

- Added Double Deck cabin type support from ELVX data and explicit CSV fields, including cabin type in equipment details and lift configuration grouping.
- Displayed double-deck capacity as `1800×2` in PDF and XLSX reports while preserving the source capacity value.
- Sorted building, service, and traffic floor rows from highest to lowest numeric elevation in PDF and XLSX reports; kept each floor on its own row and retained traffic continuation pages at 24 rows.
- Expanded report metric labels and units for clearer interpretation.
- Excluded parking floors from the unweighted population total.
- Validated with 379 tests on .NET 10.0 and visually reviewed the final four Lot 11 PDFs. The release workflow runs the .NET 8 and .NET 10 tests and builds the Windows app and installer. Interactive Windows runtime and Excel COM behavior were not tested.
