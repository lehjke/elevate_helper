# Elevate Helper v2.1.8

- Refined the main window and ELVX editor with a clearer responsive layout, consistent surfaces, native selection semantics, larger interaction targets, and updated application artwork.
- Improved accessibility with keyboard-first navigation, explicit live-region announcements, localized validation focus and help text, text-scaling-safe icons, High Contrast resources, and system-managed motion.
- Expanded the ELVX editor with stricter project, floor, traffic, lift, shaft, cabin, door, and simulation validation while preserving supported source values and floor-reference swaps.
- Made editor and processing writes atomic, preflighted generated-copy conflicts before destructive work, and preserved existing results when preparation fails.
- Hardened queue, cancellation, shutdown, retry, and Excel-process cleanup so unfinished work and unrelated user processes are not silently discarded.
- Completed English and Russian localization for runtime statuses, batch-discovery warnings, generated job labels, and validation messages without translating user-authored names.
- Added an actionable diagnostic when the installed Peters Research Elevate copy has expired instead of reporting a secondary Run Batch error.
- Strengthened release packaging with fresh-publish defaults, payload and exit-code checks, and correct x86, x64, and ARM64 installer architecture metadata.
- Expanded regression coverage for editor invariants, localization, launcher dialogs, batch discovery, processing preflight, and atomic failure recovery.
