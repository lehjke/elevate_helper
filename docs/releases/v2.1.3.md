# Elevate Helper v2.1.3

- Added automatic recovery for the Elevate `Could not open results file` error: the affected process is terminated and its batch is restarted without deleting completed outputs.
- Extended project batch discovery to arbitrary folder names and automatic building-type detection from each `.elvx` file.
- Added independent retry actions for failed office morning and lunch scenarios while the other scenario continues running.
- Hidden the unused BETA control.
- Elevate windows now start hidden, and each Elevate process is forcibly terminated after its outputs have been written.
