# Elevate Helper v2.0.1

## Fixed

- corrected door width resolution in generated reports so width is derived from the actual `DoorOpenTime` and `DoorCloseTime` values instead of shifted worksheet rows
- added `DoorPreOpening` as a tie-breaker for ambiguous timing pairs shared by central-opening and telescopic doors
- expanded the door timing table for `ЦО` and `ТО`, including late-size rows that were previously mapped incorrectly or not mapped at all

- `dotnet build .\ElevateHelperWinUI.csproj -c Release -p:Platform=x64`
- local release packaging for `zip` and `setup.exe`
