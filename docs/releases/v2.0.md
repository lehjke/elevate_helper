# Elevate Helper v2.0

## Highlights

- Migrated the application to WinUI 3 with a refreshed desktop UI.
- Added Russian and English UI localization with runtime language switching.
- Reworked Elevate launching around Run Batch automation for more stable parallel execution.
- Added live job queue progress tracking with scenario-aware progress bars.
- Removed the VBA dependency from report generation and now export reports directly to Excel and PDF.
- Added fallback report source parsing from `.elvx` when the legacy project CSV is absent.
- Fixed report printing ranges, Cyrillic handling, and Office-specific print area rules.
- Bundled `.example` templates into release builds and installers.
- Added a proper Windows application icon across the executable, window, assets, and installer.
- Disabled publish trimming for release builds to keep Excel COM report generation working.
