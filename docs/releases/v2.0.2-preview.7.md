# Elevate Helper v2.0.2-preview.7

## Added

- BETA project batch mode for project roots containing `Office`, `Res`, and `Hotel` folders with one `.elvx` per group folder
- automatic building type detection from project folders and a manual selection dialog for `.elvx` files outside known folders
- configurable parallel run limit for project batch mode, including an unlimited option
- automatic Excel/PDF report generation after each completed project batch job, with reports saved to the project root
- retry button for failed job cards

## Fixed

- project batch report generation is serialized through one Excel COM queue to avoid concurrent PDF exports

## Validation

- `dotnet test tests/ElevateHelper.Tests/ElevateHelper.Tests.csproj`
- Windows release packaging is expected to run in GitHub Actions on tag push
