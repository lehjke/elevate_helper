# Elevate Helper v2.0.5

## Changes

- Added the installed app version to the header and a startup update check against the latest GitHub release.
- Added automatic update download/start with GitHub release asset SHA-256 digest verification.
- Added a project batch preview table before launch with building type, path, file count, scenarios, and scan warnings.
- Automatically closes Elevate `Design 1` windows after completed calculations.
- Narrows the automatic `No` response to Elevate save-confirmation dialogs only.
- Fixed prerelease-aware version comparison for update checks.
- Pinned WebView2 and Windows SDK Build Tools package versions for reproducible builds.
- Added unit tests for update checks, digest verification, and Elevate save prompt detection.
