# Elevate Helper v2.2.8

- Extended **Stop all** to cancel queued and running jobs and terminate all Elevate instances, including manually launched instances and associated calculation processes. The action remains available with an empty queue, asks for confirmation before closing unsaved documents, and reports termination failures.
- Prevented pending project discovery and retry actions from starting calculations after Stop all.
- Fixed recovery from **Could not open results file. Try again?**: acknowledge the error dialog, confirm termination of the affected Elevate process, and restart the same scenario without deleting completed results. Other calculations continue running.
- Replaced blocking dialog commands with asynchronous commands and bounded cross-process text reads so a modal dialog cannot indefinitely block recovery.
- Validation: 395 tests passed on .NET 10. A Windows VM smoke test verified error-dialog detection, OK acknowledgment, and termination of only the target test process. Full recovery during a real Elevate calculation and native item-by-item resumption remain unverified.
