# Elevate Helper v2.1.4

- Fixed batch calculations failing with `Elevate main window did not appear` after hidden-window startup was introduced.
- Elevate now starts normally, is hidden immediately after its main window handle is available, and only then receives the `Run Batch` command.
- Increased the main-window startup timeout to 15 seconds and added a Win32 fallback for detecting the Elevate window under load.
