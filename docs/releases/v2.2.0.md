# Elevate Helper v2.2.0

- Replaced the legacy Excel-exported PDF with the new six-page MLT report design for Office, Residential, and Hotel projects.
- Added branded Geologica typography, MLT colors and logo assets, redesigned covers, summaries, tables, charts, criteria, glossary, and legal notice.
- Added HC5 chart series with 1% simulation points and automatically calculated 0.5% interpolation points, including the HC5/WT value strip.
- Populates report content only from project and simulation data; removed manual placeholder sections from the client report.
- Publishes only the redesigned PDF to the user; the legacy workbook generation path remains internal for compatibility and its temporary file is removed after rendering.
