# Elevate Helper v2.0.6

## Changes

- Fixed displayed app version so update checks no longer prompt for the already installed release.
- Integrated project batch mode into the main folder input while keeping ordinary `.elvx` folder launches as the default.
- Changed failed-job retry to rerun the existing Elevate batch without recreating or overwriting prepared files.
- Improved automatic closing of Elevate save/exit confirmation dialogs with the `No` response.
- Added HC5 and AWT metrics from the latest result file to active calculation cards.
- Refined macOS-style button states, accent colors, progress bars, and task controls.
- Reduced the initial window width to 960px while preserving the existing content grid.
- Added unit tests for existing-batch retry, result metrics parsing, and close prompt detection.
