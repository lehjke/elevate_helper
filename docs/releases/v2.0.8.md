# Elevate Helper v2.0.8

- Added a calculation file card to the main workflow so a single `.elvx` file can be prepared before running calculations.
- The ELVX editor now opens the existing calculation file for the selected folder or starts from the selected building template when no file exists.
- Added editable traffic parameters to the ELVX editor: incoming, outgoing, interfloor split, handling capacity, loading time, and unloading time.
- The editor refreshes the main calculation file status after saving.
